# ZX BASIC 48/128 Emulator v32

Полная автономная браузерная версия ZX BASIC 48/128 Emulator.

## Запуск

Откройте `index.html` в современном браузере. Установка и сервер не требуются.

## Что входит

- BASIC 48K/128K, экран Spectrum и управление программами;
- встроенные игры и примеры;
- спрайтовая память, Sprite Commander и Sprite Editor;
- анимация, столкновения, прокрутка экрана и преобразования спрайтов;
- Shadow Monitor, RAM-диск, Print Screen и Shadow Paint;
- Audio Commander с MIDI, многодорожечной линейкой, 3 тональными каналами и шумом;
- TV FX и чёткий режим отображения;
- редактор спрайтов с масштабом, палитрой, прозрачностью, правой кнопкой для предыдущего цвета и шахматным фоном без мешающей сетки.

## Файлы

- `index.html` — основная версия для запуска и GitHub Pages;
- `ZX_BASIC_48_128_Emulator_v32_Checkerboard_Only.html` — версия с полным номером сборки.
